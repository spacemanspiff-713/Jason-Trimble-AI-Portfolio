## Featured Courses & Projects

### Computer Vision and Artificial Intelligence — ITAI 1378

#### KidMood: Classroom Emotion Recognition

KidMood is a computer vision project that classifies facial expressions into four emotion categories: Happy, Sad, Angry, and Fear. The project uses the FER-2013 dataset, TensorFlow/Keras, and MobileNetV2 transfer learning.

**Key features:**

- Folder-based image dataset loading
- MobileNetV2 transfer learning
- Model training and evaluation pipeline
- Accuracy, macro F1-score, and confusion matrix results
- Sample prediction outputs
- Final trained model and documentation
