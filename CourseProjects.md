## ITAI 1378 — Computer Vision and Artificial Intelligence

### KidMood: Classroom Emotion Recognition

**Repository:**  
https://github.com/spacemanspiff-713/KidMood-Final-Project

**Description:**  
KidMood is a facial emotion recognition system that classifies images into Happy, Sad, Angry, and Fear. It uses MobileNetV2 transfer learning with TensorFlow/Keras and includes training, evaluation, inference, and documentation.

**Skills Demonstrated:**

- Image classification
- Transfer learning
- TensorFlow/Keras
- Dataset preprocessing
- Model evaluation
- Confusion matrix analysis
- GitHub project documentation
